# דיווח חודשי

כלי חינמי להכנת הדיווח החודשי של מטפלים למשרד הביטחון: רשימת מטופלים, חישוב מע״מ וסה״כ לכל טופס, וטבלה חודשית מוכנה להעלאה.

## פרטיות

- כל המידע נשמר רק בתיקייה שהמשתמש בוחר במחשב שלו, מוצפן בסיסמה שלו (AES-GCM).
- האתר לא שולח מידע לשום שרת. מדיניות האבטחה (CSP) חוסמת כל חיבור החוצה.
- אין בריפו הזה שום מידע של מטופלים.

## פיתוח

```
npm install
npm run dev
npm run build
```

כל דחיפה ל-`main` מעלה גרסה חדשה ל-GitHub Pages.
